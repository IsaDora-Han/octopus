## 고치는 법

`index.html` 하나만 수정하면 됩니다.

- **일정·일감·자동화**: `<!-- 오피스 현황 -->` 패널의 HTML
- **캐릭터 위치·말풍선**: 스크립트의 `ACTORS` 배열 (`x`, `y`는 오피스 박스 기준 %)
- **캐릭터 그림**: 스크립트의 `FIG` 객체 (인라인 SVG)

```bash
git add -A && git commit -m "대시보드 업데이트" && git push
```

푸시하면 1분 안에 GitHub Pages에 자동 반영됩니다.
